# Checking a suspicious link safely

Source: Google Safe Browsing / VirusTotal documentation summaries (curated)
Applies to: links in SMS, email, WhatsApp and chat

Do not click a suspicious link to find out what it is. Check the domain
itself: a brand name inside a domain is not proof it belongs to that
brand, a padlock (HTTPS) only means the connection is encrypted, and a
shortened link hides its destination. A clean result from a reputation
service does not prove safety, especially for a domain created very
recently that no service has seen yet. A URL that shows a brand before
an '@' sign has a different real host after the '@'. Never paste a link
containing a session token into a public checker without stripping it.
